# 系统架构讲稿

主线：系统总览 → 控制器建树 → 卫星转发 → 切换适应。

## 第 1 页：系统架构总览

论文要完成的是同一份视频向多个地面用户的分发。围绕这项业务，系统分为路由规划和数据执行两个相互衔接的环节：地面 SDN 控制器确定怎样连接源与接收端，卫星网络按照这个结果传送数据。

图上方的控制器掌握网络拓扑和组成员的逻辑位置，利用 RST 或 RSA 计算组播树，再把树组织成有序段列表，配置到源卫星。注意这里向下的箭头指向源端，表示控制器把计算结果交给源卫星执行。

随后沿下方的数据路径来看。地面视频源把数据送入源卫星，源卫星将段列表封装为标签栈。段内中继读取活动标签，朝当前段的终点转发；到达树成员节点后，再按子节点复制数据包、更新标签。如果该卫星连接着地面用户，就把数据交付给用户。这样，控制器算出的组播树就转化成了实际的数据分发路径。

右侧把这一组织关系归纳为规划、执行和切换适应。前两者通过源端配置和包头标签连接，后者通过逻辑地址映射，把树上的逻辑位置对应到当前服务的卫星。

要让这套流程真正运行，控制器首先需要得到可计算的网络与组成员位置。因此，下面先沿着控制器这一侧，说明它使用什么输入，以及怎样把输入变成源卫星能够执行的路由结果。

## 第 2 页：控制器：从网络模型到组播树

控制器使用的输入有两类。第一类是每个时隙的网络拓扑，第二类是视频源和各个接收端的逻辑位置。这两类信息共同确定了组播树需要在哪张网络上、连接哪些终端。

先看拓扑输入。论文采用四邻接卫星网络，上下是轨内链路，左右是相邻轨道之间的链路。轨道缝两侧不建立跨缝链路，极区卫星休眠，因此模型研究一侧非极区形成的独立网格。右边的原图展示了这个网格：卫星表示为二维坐标，星间链路表示为边，各边具有相同的带宽容量。

卫星虽然运动，但轨道和速度已知，系统可以把运行时间划成短时隙，预先确定各时隙的拓扑。在一个时隙内，用户连接的卫星保持固定，控制器就可以基于这一时隙的网格进行计算。

再看组成员的位置。地面源和接收端用所在区域关联的地标地址表示，控制器已知这些逻辑位置。把它们放入网格以后，控制器选择 RST 或 RSA 连接源与接收端，得到组播树，并将树组织成有序段列表，配置到源卫星。具体怎样构造两种树，将由后面的算法部分展开。

到这里，控制器已经把网络和成员信息转换成了路由结果。这个结果接下来要随数据包进入卫星网络，由不同节点分别执行对应的转发动作。

## 第 3 页：卫星：从标签到数据交付

控制器产生的有序段列表，正是卫星执行转发的依据。现在沿一份数据的传送过程，看看这个路由结果怎样被使用。

首先，地面源把数据交给本区域当前连接的源卫星。源卫星读取控制器配置的段列表，将它编码为数据包头部的标签栈。当前活动标签指明这一段的局部目的地，因此路由指令可以随数据包一起进入星间网络。

数据经过段内中继时，中继根据活动标签和自身邻接信息，朝局部目的节点选择下一跳。这里展示的是源路由模式，中继依靠报文携带的信息完成转发，无需保存整棵组播树。

到达当前段的终点后，树成员节点读取自己的子节点信息，为后续分支复制数据包，并更新活动标签，分别启动下一段。右边原图中的标签栈变化，展示的就是这种沿树推进的过程。与中继只负责当前段内前进相比，树成员还承担后续分支的启动。

当某颗卫星连接了接收用户时，它会在向用户交付前移除报头。这样，控制器给出的树经过源端封装、段内转发和树节点分支，最终落实为一对多的数据交付。

整个执行过程都依赖标签中的逻辑地址能够对应到当前服务的卫星。卫星发生切换时，这个对应关系由地标地址与卫星之间的映射来维持。

## 第 4 页：切换：逻辑树与物理卫星的映射

建树时使用了组成员的逻辑位置，转发时使用了标签中的逻辑目的地址，两者依靠同一套地面地标体系联系起来。这也是系统适应卫星切换的基础。

看右边的原图，地面被划分为以地标为中心的区域，地标具有逻辑地址。区域内的用户和当前服务该区域的卫星，都用关联地标表示。控制器先根据组成员的地标地址构造逻辑组播树，再把这棵树映射到当前服务各区域的卫星上。

左边两个框说明了切换时保持什么、更新什么。用户更换所连接的卫星后，仍可使用所在区域的逻辑地址；实际变化的是由哪颗卫星来承载这个区域。卫星需要同步更新关联地标、自身逻辑地址，以及四个邻居的逻辑地址，从而让逻辑目的地继续对应到当前可用的物理节点。

由于轨道和速度已知，系统可以预测各时隙中卫星与区域的关联。地址映射的同步更新还需要卫星与用户保持同步时钟。在这一条件下，逻辑树可以随着映射，对应到当前的卫星网络，数据仍按逻辑地址完成寻址和转发。

现在回到最开始的架构图：控制器在逻辑网格上计算和配置路由，源端把结果写入报文，沿途卫星执行逐段转发与分支，地址映射则把这一过程连接到持续运动的物理卫星。后面介绍的树构建、段内路由和树管理算法，都是在这一组织方式上进一步解决具体问题。
